  1. Gå til GitHub Token-innstillinger.
  2. Klikk på Generate new token ➔ Generate new token (classic).
  3. Gi tokenet et beskrivende navn, f.eks. Beveren Redaktør.
  4. Under Select scopes, merk av for repo (dette tillater at editoren kan lese og skrive artikler direkte i repositoriet ditt).
  5. Rull helt ned og klikk på den grønne Generate token-knappen.
  6. Kopier tokenet (det starter med ghp_) og lim det inn over.

Sikkerhet: Tokenet ditt lagres utelukkende lokalt i din egen nettleser (localStorage) og sendes kun direkte til GitHubs offisielle servere. Ingen tredjeparter er involvert.
